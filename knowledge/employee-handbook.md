# 임직원 업무 가이드

## 휴가 정책

연차 휴가는 최소 3영업일 전에 사내 인사 시스템에서 신청합니다. 긴급한 경우에는 먼저 리더에게 알린 후 당일 신청할 수 있습니다. 연속 5영업일 이상 휴가는 업무 인수인계 문서를 첨부합니다.

## 보안 정책

고객 데이터와 비밀정보를 외부 생성형 AI 서비스에 입력해서는 안 됩니다. 외부 도구 도입 전 보안 검토와 개인정보 영향 평가를 완료해야 합니다. 운영 권한은 최소 권한 원칙에 따라 부여하고 분기마다 검토합니다.

## 비용 정책

팀 단위 AI API 비용은 월별 예산과 사용량 알림을 설정합니다. 새로운 상용 모델을 운영에 적용하기 전 품질, 지연 시간, 비용을 동일한 평가셋으로 비교합니다.
